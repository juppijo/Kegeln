Gebrauchsanweisung: Kegel-Server & Hotspot

Diese Anleitung beschreibt die einmalige Einrichtung und den täglichen Start des Node.js Kegel-Servers in Kombination mit dem Windows-WLAN-Hotspot für die Smartphones.

Voraussetzung: Auf dem Computer muss Node.js installiert sein. Falls nicht, lade es zuerst von der offiziellen Website herunter und installiere es.

1 Einmalige Windows-Hotspot Vorbereitung

Damit die Smartphones sich korrekt verbinden können, müssen Name und Passwort im Windows-System hinterlegt sein:

  1. Öffne die Windows-Einstellungen (Tastenkombination: Windows-Taste + I).
  2. Navigiere zu Netzwerk und Internet → Mobiler Hotspot.
  3. Klicke auf Bearbeiten und vergebe den gewünschten Netzwerknamen (SSID) und ein sicheres Netzwerkkennwort.
  4. Stelle sicher, dass die Freigabe über WLAN konfiguriert ist. Du kannst den Hotspot danach wieder ausschalten – das Skript übernimmt das zukünftig automatisch.

2 Projekt-Abhängigkeiten installieren

Bevor der Server das erste Mal starten kann, müssen die benötigten Node-Module geladen und die Start-Hilfe installiert werden:

  1. Öffne die Windows-Eingabeaufforderung (CMD).
  2. Installiere nodemon global, damit das Skript automatische Neustarts bei Code-Änderungen durchführen kann: 
    npm install -g nodemon
  3. Wechsle in deinen Projektordner: 
    cd C:\Users\juppi\Documents\KEGEL_APPS\Kegeln-2b
  4. Installiere alle für die Kegel-App notwendigen Pakete: 
    npm install

3 Den Server & Hotspot starten

Für den täglichen Betrieb nutzt du die Datei kegel_hotspot_starten.bat:

  • Führe die Datei einfach per Doppelklick aus.
  • Wichtig: Bestätige die Windows-Abfrage nach Administratorrechten (UAC) mit "Ja". Diese Rechte werden benötigt, um den Hotspot im Hintergrund per PowerShell zu aktivieren.
  • Das Skript startet nun selbstständig den WLAN-Hotspot und fährt direkt im Anschluss den Node.js Server hoch.
Achtung beim Beenden: Schließe das schwarze Konsolenfenster erst, wenn das Kegeln beendet ist. Sobald das Fenster geschlossen wird, stoppt auch der Server. Der Windows-Hotspot bleibt in der Regel aktiv, bis Windows heruntergefahren wird oder du ihn manuell in den Einstellungen deaktivierst.

4 Smartphones verbinden

  1. Aktiviere WLAN auf den Smartphones der Spieler.
  2. Verbinde die Smartphones mit dem in Schritt 1 festgelegten WLAN-Hotspot.
  3. Öffne den Browser auf dem Smartphone und gib die IP-Adresse des Server-PCs gefolgt vom Port der Kegel-App ein (z. B. http://192.168.137.1:3000).
