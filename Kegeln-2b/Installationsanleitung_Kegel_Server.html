Einrichtung des Kegel App Servers & WLAN-Hotspots unter Linux

Diese Dokumentation führt dich Schritt für Schritt durch die komplette Installation des Express-Servers auf einem Linux-System sowie die Bereitstellung des lokalen Netzwerks via WLAN-Hotspot für die Smartphones im Klub.

Teil 1: Vorbereitung des Linux-Systems

  1. Node.js & npm installieren: Öffne das Terminal und installiere die Laufzeitumgebung. 
    sudo apt update && sudo apt install nodejs npm
  2. Server-Verzeichnis erstellen: Lege den Hauptordner für das Projekt an. 
    mkdir -p ~/Kegel-Server && cd ~/Kegel-Server
  3. Webseiten-Dateien hinterlegen: Kopiere deinen vollständigen Frontend-Ordner Kegeln-2b (der die index.html, Styles und Skripte enthält) direkt in dieses neue Verzeichnis.

Teil 2: Projekt & Abhängigkeiten einrichten

  1. Projekt initialisieren: Erstelle im Ordner ~/Kegel-Server die Konfigurationsdatei. 
    npm init -y
  2. Express & Nodemon installieren: Installiere das Web-Framework und das Entwicklungswerkzeug. 
    npm install express && npm install --save-dev nodemon
  3. Start-Skript konfigurieren: Öffne die Datei package.json mit einem Editor (z.B. nano package.json) und trage unter "scripts" die dev-Zeile ein: 
    "scripts": {
  "dev": "nodemon -L index.js"
}

Teil 3: Die Server-Datei erstellen

Erstelle im Ordner ~/Kegel-Server eine Datei namens index.js und füge folgenden Code ein. Dieser bedient die statischen Dateien aus Kegeln-2b und stellt die Daten-API bereit:

const express = require('express');
const http = require('http');
const path = require('path');
const os = require('os');

const app = express();
const server = http.createServer(app);
const PORT = 3000;

app.use((req, res, next) => {
    res.setHeader('Cache-Control', 'no-store, no-cache, must-revalidate, proxy-revalidate');
    next();
});

app.use(express.json());
app.use(express.static(path.join(__dirname, 'Kegeln-2b')));

let globalKegelData = { players: [], activeGamesData: {}, grandTotalScores: {} };

app.get('/api/data', (req, res) => res.json(globalKegelData));
app.post('/api/data', (req, res) => {
    const incomingData = req.body;
    if (incomingData.activeGamesData) globalKegelData.activeGamesData = incomingData.activeGamesData;
    if (incomingData.players && incomingData.players.length > 0) globalKegelData.players = incomingData.players;
    if (incomingData.grandTotalScores) globalKegelData.grandTotalScores = incomingData.grandTotalScores;
    res.json({ status: "success" });
});

function getLocalIpAddress() {
    const interfaces = os.networkInterfaces();
    for (const name in interfaces) {
        for (const iface of interfaces[name]) {
            if ((iface.family === 'IPv4' || iface.family === 4) && !iface.internal) {
                return iface.address;
            }
        }
    }
    return '127.0.0.1';
}

server.listen(PORT, '0.0.0.0', () => {
    console.log(`=== 🎳 KEGEL APP SERVER läuft unter: http://${getLocalIpAddress()}:${PORT} ===`);
});

Teil 4: Netzwerk-Hotspot via Terminal einrichten

Falls in deiner Desktop-Oberfläche kein Hotspot-Button existiert, nutze die Linux-Netzwerksteuerung (nmcli):

  1. Namen des WLAN-Geräts ermitteln: 
    nmcli device
    Suche in der Spalte TYP nach wifi und notiere den Namen aus der Spalte GERÄT (z.B. wlp3s0).
  2. Hotspot aktivieren: Ersetze DEIN_GERÄT durch den ermittelten Namen: 
    sudo nmcli device wifi hotspot ssid Kegelklub_Gut_Holz password 12344321 ifname DEIN_GERÄT
  3. Hotspot-IP-Adresse überprüfen: 
    ip addr show DEIN_GERÄT
    Suche nach inet (meistens lautet die Adresse 10.42.0.1).

Start im Klub: Starte den Server im Projektordner mit npm run dev. Die Mitglieder verbinden ihre Smartphones mit dem WLAN Kegelklub_Gut_Holz und rufen im Browser http://10.42.0.1:3000 auf.

Hotspot beenden: Nach dem Kegeln schaltest du den Hotspot mit sudo nmcli device disconnect DEIN_GERÄT wieder ab, um das normale WLAN zu nutzen.
